# Sinu Uus Maa kodu

Hei. Mul on vaja luua kinnisvaramaakleri koduleht. Kuulutusi sinna ei pane vaid minu pakkumiste osas suunaks Uus Maa lehele minu profiilile. Kasuta palun Uus Maa värve kodulehel, et oleksin samades toonides. Tooks siis lehel välja, kes ma olen, mis teenust pakun, müük, ost, üür ja konsultatsioom. Minu kontaktid, siis ka blogi osa ja tagasisided. Leht peaks olema selline soe, et kes sinna satub saab hea emotsiooni. Ehk siis leht mis müüb ise ennast
